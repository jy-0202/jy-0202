## 🍽️ [DiningCode Dynamic Crawling Pipeline](https://github.com/jy-0202/diningcode-dynamic-crawling-pipeline)

> **동적 웹 데이터의 수집부터 검증 · 적재 · 자동 실행까지 구성한 데이터 파이프라인**

`Python` `Selenium` `BeautifulSoup` `Pandas` `MySQL` `pytest` `Ruff` `GitHub Actions` `GCE`

### Architecture

**Selenium → Raw HTML → Extract → Interim CSV → Preprocess & Validation → Processed CSV → MySQL UPSERT**

### Key Features

- Selenium 기반 JavaScript 동적 페이지 데이터 수집
- **Raw / Interim / Processed** 데이터 계층 분리
- Crawling · Extract · Preprocess · Load 단계별 모듈화
- `batch_id` 기반 실행 단위 데이터 관리
- 필수값 · 식별자 · URL 중복 등 단계별 데이터 품질 검증
- PK / UNIQUE 제약과 UPSERT를 활용한 반복 실행 데이터 정합성 관리
- 외부 사이트와 DB 의존성을 분리한 pytest 단위 테스트 구성
- Ruff 정적 코드 검사 및 GitHub Actions CI 구성
- Windows Self-hosted Runner 기반 전체 파이프라인 자동 실행
- Google Compute Engine 기반 Linux 실행 환경 구성
- CI 성공 후 GCE로 이어지는 CD 자동화

### Result

**75개 후보 → URL 중복 제거 → 71개 음식점 × 16개 컬럼**

`필수값 오류 0건` · `중복 0건`

초기 **Raw CSV 중심 구조를 Raw HTML → Extract 구조로 개선**하여 수집과 파싱의 책임을 분리하고,  
저장된 원본 HTML을 재사용함으로써 데이터 처리 과정에서 불필요한 재크롤링을 줄였습니다.
